## Lessons that change the recommendation

1. Dense image output and low-friction draft entry are parity, not a moat.
2. Reciprocal matches are also parity in emerging tools. Win the last mile: exact
   constraints, explicit offers, freshness, actionable search, two-sided preparation.
3. Do not require both people to install or join before seeing value. An anonymous
   recipient can check a few owned offers locally against a published list.
4. Do not import competitor inventories, artwork or identities. Support portable
   user-authored text and share links only through explicit, validated import later.
5. Avoid a global price/rarity score: desirability is personal, liquidity local,
   and multi-trade 'deals' create risk. A mutual overlap is not an agreed exchange.
6. Permissioned community reach matters more than globally large match totals.
   A small network must remain useful as a share/preparation tool at zero matches.
