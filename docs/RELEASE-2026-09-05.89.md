# Phase 1: contextual, honest Pokemon GO searches

Candidate release `2026-09-05.89`, based on accepted main `a30a341` and live `.88`
source `b6abc07d103fef194809383cda91e96a39e4531a`. No prototype runtime code is
included. Design reference: `design/trade-intent-study-2026-09`, workflows and roadmap.

## Scope and contract

- My List: current Looking For/For Trade category and current visible filter.
- Existing bulk-selected legacy entries, plus Board's selected canonical declarations
  across both sides. Selection stays referential; no second record/store.
- Reciprocal comparison: what I offer and what they offer use the existing exact
  declaration intersections and availability guards. Shared wants stay separately labeled.
- Public v1/v2 and signed-in share views: current permitted intent/category only.

Every new contextual query is **species-only**, with localized `!traded` plus
deduplicated species numbers. No CP cap, shiny/background exclusion, possession,
eligibility or safe-transfer claim. Exact form/costume/BG/gender/shiny/Max and other
details require manual verification; all source entries remain in the review list.
Unresolved species are explicitly counted and named, never parsed from costume
years or silently discarded. Empty/all-unresolved sets emit no broad query.
Oversized sets split at species boundaries using the existing 1500-character
supported budget; each part is copied separately with identical displayed bytes.
EN/JA/ES/DE use the existing canonical serializer and game-language preference.
Legacy advanced priority and safe-transfer presets are unchanged, not reused here.

Anonymous bootstrap adds only the already-allowlisted UI string helper. No Auth,
private viewer reads, account-sync modules or new network calls. The helper reads
only the public projection already admitted by the public route. No new runtime
path or Pages allowlist/control revision is required.

## Preservation

No storage model, migration, writes, UID logic, permissions, notes, priorities,
provider flags, Rules, reset runtime, or recovery66 change. Search panels are
cleared at session boundaries. Existing `.88` closeout README/state corrections
are carried alone from the design branch; the design branch is not merged.
The App Check-blocked non-owner live probe remains explicitly unproven live.

## Qualification

Focused model tests cover empty/unknown/mixed, size splitting, all query locales,
manual text escaping, input immutability, and give/receive direction. Browser
journeys cover current filters including BG aliases, bulk and Board scope,
language refresh, public v1/v2, copy failure recovery, narrow/desktop geometry,
and no account mutation/private anonymous reads. Normal changed-area CI and the
accepted Pages release gate are required before deployment. Evidence counts and
exact PR/source/run identifiers are recorded in the release closeout, not guessed.
