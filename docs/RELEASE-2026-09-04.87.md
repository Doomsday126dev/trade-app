# Product release 2026-09-04.87

This release follows production 2026-08-31.86 and ships the accepted product model:

- Looking For and For Trade in My List, with neutral unprioritized entries.
- Unified public LF/FT sharing and compatibility with existing LF-only links.
- Anonymous search copying and viewer-language EN/JA/ES/DE output.
- Reciprocal Compare based on explicit declarations.
- Board curation/image export and My List / Trainers / More navigation.
- Share via Link / Image / Text, with publication and clipboard success distinct.
- Healthy existing Username/PIN accounts eligible for canonical synchronization
  independently of the former canary list.

PIN reset is deferred to .88 or a later bounded backend release. Normal sign-in,
sync, editing, sharing and release rollback do not depend on it. The unsafe
replacement-UID reset remains blocked for established accounts. Safe owner-assisted
reset requires a separately implemented trusted backend that updates the existing
UID without moving data or exposing the old PIN.

The release validator is refreshed to the reviewed product asset inventory;
exact inventory, release coherence and rollback checks remain enforced.

No provider rollout, PIN-reset backend, physical Board migration or legacy-data
purge is included. Google remains publicly hidden and Discord disabled.
