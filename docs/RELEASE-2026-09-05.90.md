# 2026-09-05.90: combined intent editing and scoped sharing

Production candidate from the accepted .89 source, not prototype runtime.

## Product contract

- Desktop: My List / Trainers / Events / More. Mobile: My List / Trainers / More;
  Events remains under More.
- One compact row groups matching variant declarations. A shared editor supports
  independent Looking For and For Trade, including both. FT is willingness to
  trade, not an inventory record, quantity, specimen, or ownership assertion.
- Existing source references and canonical mutation batches remain authoritative.
  Notes, qualifier flags and H/M/L are retained. Top want changes LF priority only.
  Conflicting canonical slots fail without overwriting another variant. Stale
  drafts and failed writes remain visible instead of reporting success.
- Full list offers Link / Image / Text. Top wants and Selected entries offer only
  Image / Text. No subset-link publication or warning-labeled full link escape.
- Preview and local outputs use the same declaration snapshot. Link retains the
  existing full-list publication acknowledgement and separate copy-failure state.
- Board selection feeds selected-scope Share. Legacy Board records are not
  physically rewritten by this presentation change. Missing image art has a text
  identity, and long qualifiers receive measured wrapping rather than truncation.
- Existing public notes remain public intent fields; private trainer tags and
  notes are not collected by these output adapters. Public v1/v2 readers unchanged.

## Qualification and boundaries

Focused browser coverage includes both-side canonical saves, reopen persistence,
selection through filtering, subset output exclusion, failed saves/publication,
missing-art images, long qualifiers, mobile geometry and existing Board behavior.
The existing performance gates retain their thresholds. Legacy compatibility
journeys explicitly open Advanced list tools, where those controls now live.

No data/schema migration, identity change, provider activation, PIN reset, Rules,
IAM, Firebase deployment, recovery66 change, or PR63 operator workflow is included.
No ordinary account was mutated during qualification.

## Retained and deferred

The old primary direction/category editor is demoted to Advanced list tools for
legacy bulk/reorder compatibility, not deleted from storage. Fragmented classic/
card/CSV choices are removed from the main Share flow. Existing lower-level export
functions remain for compatibility callers. Subset public links and a new variant
storage identity are out of scope. Extremely tall images fail explicitly at the
canvas safety limit; multipage/archived export is deferred rather than omitting
entries. The compact list loads another 120 groups on explicit Show more.
